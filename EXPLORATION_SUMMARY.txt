KEY FINDINGS
================================================================================

SYSTEM ARCHITECTURE:
- Type: Distributed Microservices with Monolithic MVP
- Backend: FastAPI (Python 3.11+) with 140 Python files
- Frontend: Next.js (React/TypeScript)
- Database: PostgreSQL 15+ with 23 core models
- Task Queue: Celery + Redis
- Deployment: Railway (backend) + Vercel (frontend)

THE 4-TOOL ECOSYSTEM:

Tool 1: Meta-Analysis Assistant (Systematic Reviews)
- CoordinatorAgent orchestrates workflow
- SearchAgent queries PubMed/arXiv/EuropePMC/CORE
- ScreeningAgent applies inclusion/exclusion criteria
- DataExtractionAgent extracts statistics
- Reports in APA format with forest plots
- Persistent coordinator state for recovery

Tool 2: Research Direction Generator (Gap Analysis)
- Analyzes existing research landscape
- Identifies research gaps
- Generates novel research proposals
- Tracks emerging research areas
- Connects researcher expertise to opportunities

Tool 3: Peer Review Assistant (Manuscript Screening)
- AI desk review with quality scoring
- Recommendation generation (accept/minor/major/reject)
- Editor approval workflow with override capability
- Review quality metrics tracking
- Eligible_for_payout flag for contributor system

Tool 4: Expert Reviewer Matcher (AI Researcher Matching)
- Semantic expertise matching using keywords and domains
- Availability assessment (inverse of current workload)
- Conflict of interest detection
- Diversity metrics (geographic, institutional, methodological)
- Overall score = 50% expertise + 30% availability + 20% diversity
- Invitation workflow with custom messages

USER ROLES (5 levels):
- ADMIN: Full system access
- EDITOR: Approve/reject reviews, manage workflow
- RESEARCHER: Create analyses, upload manuscripts (default)
- REVIEWER: Write reviews, earn money (via $100/month subscription)
- VIEWER: Read-only access

RESEARCHER ONBOARDING (5-Step Process):
Step 1: Basic Information (name, email, institution, department, position)
Step 2: Academic Profile (ORCID, Google Scholar, ResearchGate, H-index)
Step 3: Research Expertise (1-5 domains, 5-20 keywords, methodologies)
Step 4: Peer Review Experience (0-50+ reviews, languages, capacity, timeframe)
Step 5: Subscription & Payment (Stripe $100/month subscription)
Post-Onboarding: AI enrichment from Google Scholar + ORCID

================================================================================
CRITICAL CODE PATHS
================================================================================

1. META-ANALYSIS WORKFLOW:
   POST /api/v1/meta-analysis/create
   → MetaAnalysisService creates DB record
   → CoordinatorAgent initialized
   → Workflow plan persisted
   → SearchAgent searches databases
   → Papers downloaded + stored
   → ScreeningAgent applies criteria
   → DataExtractionAgent extracts statistics
   → Statistical analysis performed
   → APA report generated
   → Results returned

2. REVIEWER MATCHING:
   POST /api/v1/reviewer-matcher/match/search
   → Query Researcher table with filters (h-index, citations, workload)
   → Calculate expertise_score (keyword + domain + h-index)
   → Calculate availability_score (inverse workload + response rate)
   → Calculate diversity_score (geographic + institutional)
   → overall_score = 0.5*expertise + 0.3*availability + 0.2*diversity
   → Detect conflicts of interest
   → Return top N candidates ranked

3. PEER REVIEW WORKFLOW:
   Manuscript submitted
   → AI desk review (generate initial scores + recommendation)
   → Editor reviews and can override
   → If approved: AI generates full review
   → Editor reviews generated review
   → Editor can approve/request revisions
   → Final review sent to author
   → If approved: mark eligible_for_payout

4. SUBSCRIPTION & PAYOUTS:
   Researcher subscribes ($100/month via Stripe)
   → Subscription model created + linked
   → Review accepted and approved
   → PayoutContribution recorded
   → Monthly payout pool calculated
   → PayoutDistribution created (pro-rata share)
   → Payout via Stripe Connect
