# Target Researchers List

## Overview
This document provides a curated list of 50+ psychology researchers across 5 specializations for recruitment. Target: 10 researchers for proof of concept (2 from each specialty).

**Selection Criteria:**
- Active publications (2023-2024)
- H-index ≥10 preferred
- Accessible contact information
- Top-tier institutions prioritized
- Strong Google Scholar profiles

---

## How to Use This List

### Phase 1: Initial Outreach (Top 20)
Start with the "Priority" researchers (marked with ⭐). These have:
- Recent publications in high-impact journals
- Public email addresses
- Strong online presence
- Active research groups

### Phase 2: Secondary Outreach (Next 20)
If response rate is <50%, expand to secondary list.

### Phase 3: Broad Outreach (Remaining 10+)
Final push to reach 10 committed researchers.

## Data Collection Instructions

### For Each Researcher, Verify/Collect:

1. **Contact Information**
   - Primary email (check department website)
   - LinkedIn profile (if available)
   - Twitter/X handle (if active)
   - Research group website

2. **Google Scholar Profile**
   - Full URL
   - Current H-index
   - i10-index
   - Citation count
   - Recent publications (2023-2024)

3. **ORCID Profile** (if available)
   - ORCID iD number
   - Link to profile

4. **Recent Activity**
   - Last publication date
   - Recent conference presentations
   - Active grants (check NIH Reporter, NSF awards)
   - Lab website update frequency

5. **Social Signals**
   - ResearchGate score (if available)
   - Twitter followers (if applicable)
   - Blog or public writing
   - Media presence

### Research Tools:

- **Google Scholar:** Search by name + institution
- **University Websites:** Department directories for email
- **PubMed:** Recent publications
- **ResearchGate:** Activity level and engagement
- **LinkedIn:** Professional presence
- **Twitter/X:** Academic activity and engagement
- **ORCID:** https://orcid.org/orcid-search/search
