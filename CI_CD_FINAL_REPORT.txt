================================================================================
                           TROUBLESHOOTING
================================================================================

COMMON ISSUES AND SOLUTIONS:

1. Workflows Not Triggering
   Solution: Check YAML syntax, verify branch names, force trigger

2. Tests Failing in CI
   Solution: Match CI environment locally, check service availability

3. Coverage Not Uploading
   Solution: Verify Codecov token, check coverage file exists

4. Security Scans Failing
   Solution: Update dependencies, run locally first, adjust severity

5. Permission Errors
   Solution: Check Actions settings, enable read/write permissions

6. Badge Not Showing
   Solution: Update URLs, wait for first workflow run, check format
