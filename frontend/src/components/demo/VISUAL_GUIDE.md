## Typography Hierarchy

### Floating Badge
- Font: Sans-serif
- Size: text-2xl (24px)
- Weight: Bold
- Color: White
- Background: White/10 blur
- Border: White/20
- Padding: 12px 24px

### Stage Titles
- Font: Sans-serif
- Size: text-6xl to text-8xl (60-96px)
- Weight: Bold
- Color: White
- Line height: Tight

### Body Text
- Font: Sans-serif
- Size: text-xl to text-2xl (20-24px)
- Weight: Normal to Medium
- Color: White/80
- Line height: Relaxed

### Numbers (Stats)
- Font: Sans-serif
- Size: text-6xl (60px)
- Weight: Bold
- Color: White
- Tabular numbers

## Responsive Adaptations

### Mobile (< 768px)
- Reduce font sizes by 30-40%
- Stack grid layouts vertically
- Reduce particle count (50 → 25)
- Increase control button sizes
- Simplify backgrounds
- Shorter height (80vh vs 100vh)

### Tablet (768px - 1024px)
- Slightly reduce font sizes (10-20%)
- Maintain grid layouts
- Full particle effects
- Standard control sizes
- Full backgrounds

### Desktop (> 1024px)
- Full font sizes
- Maximum particle effects
- Parallax backgrounds
- Enhanced glow effects

---

## Accessibility Features

### Visual
- High contrast text (white on dark)
- Clear focus indicators
- Large touch targets (44px+)
- Color is not sole indicator

### Motion
- Respects `prefers-reduced-motion`
- Pause control always available
- No automatic rapid flashing

### Screen Readers
- ARIA labels on all controls
- Stage announcements
- Progress indicators
- Descriptive button text
