# Research Direction Finder - Tool 2

## Overview

The **Research Direction Finder** is an AI-powered tool that analyzes completed meta-analysis results to identify research gaps and generate novel, actionable research directions. It's the second tool in the 4-tool Meta-Analysis Research Platform.

- **Integration**: Connected to Meta-Analysis (Tool 1)

## Features

### 1. Gap Identification
Automatically identifies 5-7 significant research gaps across multiple dimensions:
- **Methodological gaps**: Study design limitations, missing analytical approaches
- **Population gaps**: Understudied demographics, geographic limitations
- **Outcome gaps**: Unmeasured or poorly measured outcomes
- **Theoretical gaps**: Missing conceptual frameworks
- **Geographic gaps**: Regional coverage limitations
- **Temporal gaps**: Time period biases
- **Interdisciplinary gaps**: Missed cross-field opportunities

Each gap includes:
- Detailed description
- Evidence from meta-analysis
- Severity rating (critical/high/medium/low)
- Impact potential (0.0-1.0)
- Feasibility score (0.0-1.0)
- Expert reasoning

### 2. Research Question Generation
Generates 7-10 novel, specific research questions that:
- Address identified gaps
- Build on meta-analysis findings
- Use PICO format (when applicable)
- Include feasibility assessment
- Provide novelty scores
- Link to specific gaps

Each question includes:
- Clear, answerable question
- Detailed rationale
- Expected contribution
- Feasibility score
- Novelty score
- Priority level

### 3. Research Proposal Creation
Creates 3-5 detailed, publication-ready research proposals featuring:

**Core Components**:
- Compelling title
- Background and significance
- Innovation statement
- Detailed methodology:
  - Study design (RCT, observational, systematic review, etc.)
  - Target population and sample size
  - Intervention/exposure details
  - Comparison/control specification
  - Primary and secondary outcomes
  - Measurement instruments
  - Statistical analysis plan
  - Data collection methods
- Expected outcomes and impact
- Timeline (duration estimate)
- Budget category (low/medium/high)
- Key challenges and mitigation strategies

**Scoring System**:
- **Feasibility score** (0.0-1.0): How achievable the study is
- **Impact score** (0.0-1.0): Potential contribution to the field
- **Novelty score** (0.0-1.0): How innovative the approach is

### 4. Priority Ranking
Automatically ranks proposals using a composite score:
- **Impact**: 40% weight
- **Feasibility**: 35% weight
- **Novelty**: 25% weight

### 5. Completeness Assessment
Provides a completeness score (0.0-1.0) based on:
- Number of gaps identified (target: 5+)
- Number of questions generated (target: 7+)
- Number of proposals created (target: 3+)
- Diversity of gap types (target: 4+ types)
- Average quality scores

## API Endpoints

### 1. Generate Research Directions
```bash
POST /api/v1/research-direction/generate
```

**Request Body**:
```json
{
  "meta_analysis_id": "uuid-of-completed-meta-analysis",
  "focus_areas": ["methodology", "populations"],  // Optional
  "max_proposals": 5,  // 1-10, default: 5
  "include_literature_review": true
}
```

**Response**: Complete research direction analysis with gaps, questions, and proposals.

**Requirements**:
- Meta-analysis must have status = "completed"
- User must own the meta-analysis
- Valid authentication token

### 2. Get Research Directions
```bash
GET /api/v1/research-direction/by-meta-analysis/{meta_analysis_id}
```

Retrieves previously generated research directions for a specific meta-analysis.

### 3. Get History
```bash
GET /api/v1/research-direction/history?skip=0&limit=20
```

Lists all research directions generated by the current user.

### 4. Delete Research Direction
```bash
DELETE /api/v1/research-direction/{direction_id}
```

Deletes a research direction (soft delete).

## Usage Example

### Complete Workflow

```python
import httpx

BASE_URL = "http://localhost:8000/api/v1"
TOKEN = "your-auth-token"

headers = {
    "Authorization": f"Bearer {TOKEN}",
    "Content-Type": "application/json"
}

# Step 1: Complete a meta-analysis
meta_analysis_id = "existing-completed-meta-analysis-id"

# Step 2: Generate research directions
response = httpx.post(
    f"{BASE_URL}/research-direction/generate",
    headers=headers,
    json={
        "meta_analysis_id": meta_analysis_id,
        "focus_areas": ["methodology", "populations", "outcomes"],
        "max_proposals": 5,
        "include_literature_review": True
    }
)

result = response.json()

print(f"Identified {len(result['gaps_identified'])} gaps")
print(f"Generated {len(result['research_questions'])} questions")
print(f"Created {len(result['research_proposals'])} proposals")
print(f"Completeness: {result['completeness_score']:.1%}")

# Step 3: Access top priority proposal
top_proposal = result['research_proposals'][0]
print(f"\nTop Priority Proposal:")
print(f"Title: {top_proposal['title']}")
print(f"Feasibility: {top_proposal['feasibility_score']:.2f}")
print(f"Impact: {top_proposal['impact_score']:.2f}")
```

## Agent Architecture

### ResearchDirectionAgent

The core AI agent uses Claude Sonnet 4.5 with specialized prompts for:

1. **Gap Analysis**: Examines meta-analysis results for systematic patterns
2. **Question Brainstorming**: Generates creative, rigorous research questions
3. **Proposal Drafting**: Creates detailed, grant-ready proposals
4. **Quality Assessment**: Scores feasibility, impact, and novelty

**Key Methods**:
- `process()`: Main entry point for complete analysis
- `_identify_gaps()`: Identifies research gaps with evidence
- `_generate_questions()`: Creates research questions
- `_create_proposals()`: Drafts detailed proposals
- `_rank_proposals()`: Priority ranking by composite score
- `analyze_meta_analysis()`: High-level database-integrated method

## Database Schema

### ResearchDirection Model

```sql
CREATE TABLE research_directions (
    id UUID PRIMARY KEY,
    meta_analysis_id UUID NOT NULL REFERENCES meta_analyses(id) ON DELETE CASCADE,
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,

    -- Configuration
    focus_areas TEXT[],
    max_proposals VARCHAR(50),
    include_literature_review VARCHAR(50),

    -- Results (JSONB)
    gaps_identified JSONB NOT NULL,
    research_questions JSONB NOT NULL,
    research_proposals JSONB NOT NULL,
    priority_ranking JSONB,

    -- Metrics
    completeness_score FLOAT,
    num_gaps VARCHAR(50),
    num_questions VARCHAR(50),
    num_proposals VARCHAR(50),

    -- Metadata
    processing_time_seconds FLOAT,
    model_version VARCHAR(100),
    agent_version VARCHAR(50),
    analysis_metadata JSONB,

    -- Timestamps
    created_at TIMESTAMP NOT NULL,
    updated_at TIMESTAMP NOT NULL,

    -- Indexes
    INDEX idx_meta_analysis_id (meta_analysis_id),
    INDEX idx_user_id (user_id),
    INDEX idx_created_at (created_at)
);
```

## Error Handling

### Common Errors

**1. Meta-analysis not completed**
```json
{
  "detail": "Meta-analysis must be completed. Current status: in_progress"
}
```
**Solution**: Wait for meta-analysis to complete or manually update status.

**2. Meta-analysis not found**
```json
{
  "detail": "Meta-analysis {id} not found or access denied"
}
```
**Solution**: Verify ID and user ownership.

**3. Claude API error**
```json
{
  "detail": "Failed to generate research directions: API rate limit"
}
```
**Solution**: Retry after delay or check API key.

## Best Practices

### For Researchers

1. **Complete quality meta-analysis first**: Better input = better output
2. **Specify focus areas**: Narrow scope for more targeted gaps
3. **Review and refine**: AI suggestions should be starting points
4. **Combine with expert knowledge**: Validate feasibility claims
5. **Consider resources**: High-impact may not mean high-feasibility

## Troubleshooting

### Issue: Low completeness score

**Cause**: Insufficient meta-analysis data or poor quality input.

**Solution**:
- Ensure meta-analysis includes adequate studies (10+ recommended)
- Provide detailed inclusion/exclusion criteria
- Include study metadata (year, sample size, etc.)

### Issue: Generic proposals

**Cause**: Limited focus areas or insufficient context.

**Solution**:
- Specify focus_areas parameter
- Ensure meta-analysis has rich metadata
- Use include_literature_review: true

### Issue: Low feasibility scores

**Cause**: Agent overestimating required resources.

**Solution**:
- Review proposals manually
- Adjust scope in follow-up iterations
- Consider simpler designs first
