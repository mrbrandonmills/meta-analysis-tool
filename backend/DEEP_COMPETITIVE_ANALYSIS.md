**Revenue:** ~$15M/year (estimated)

- NO API access

**Key Features:**
✅ Clean, intuitive UI
✅ Collaboration (multiple reviewers)
✅ Conflict resolution system
✅ PRISMA diagram generator
✅ Data extraction forms
✅ Risk of bias assessment
✅ Cochrane backing (credibility)

❌ **NO automatic database searching**
❌ **NO AI screening**
❌ **Manual import only** (CSV/RIS)
❌ **No comprehensive coverage**
❌ **Expensive**

**Strengths:**
- **Brand trust:** Owned by Cochrane (gold standard)
- **User base:** 500K users = network effects

**Weaknesses:**

- **Slow innovation:** Corporate bureaucracy (Cochrane owned)
